# SK EQ

*(formerly PureEQ)*

A minimal, dark-mode 10-band system equalizer UI for **Windows** and **macOS**, built with Flutter.
It has a glowing real-time spectrum visualizer, presets, bass and treble shelves, and master volume control.

## Download

Get the latest installer from **[Releases](https://github.com/SK2601S/PureEQ/releases/latest)**:

- **Windows:** `SK-EQ-Setup-<version>.exe`
- **macOS:** `SK-EQ-<version>.dmg`

After that, SK EQ updates itself (see [Updates](#updates)).

## Building from source

Requires Flutter **3.47** (stable) with desktop support enabled. Windows builds also need Visual Studio's "Desktop development with C++" workload, and macOS builds need Xcode.

```bash
flutter pub get
flutter run -d windows     # on Windows
flutter run -d macos       # on macOS
flutter test
```

## Building installers

| Platform | Command | Output |
|---|---|---|
| Windows (on Windows) | `.\scripts\build_windows_installer.ps1` | `dist\SK-EQ-Setup-<version>.exe` |
| macOS (on a Mac) | `./scripts/build_macos_dmg.sh` | `dist/SK-EQ-<version>.dmg` |
| Both (GitHub Actions) | Actions → **Build installers** → Run workflow, or push a `v*` tag | run artifacts / GitHub Release |

The Windows installer needs [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`). It installs per-user without admin rights and bundles the Visual C++ runtime.

A `.dmg` can only be built on macOS (Xcode is required).

**Unsigned builds:** the installers aren't code-signed. On Windows, SmartScreen may show "Windows protected your PC"; click **More info → Run anyway**. On macOS, Gatekeeper blocks the first launch; right-click the app and choose **Open**, or go to **System Settings → Privacy & Security → Open Anyway**. Signing removes these warnings: Windows needs a code-signing certificate, and macOS needs an Apple Developer ID plus notarization.

The app icon is generated by `python tool/generate_icons.py`, which requires Pillow.

## Updates

SK EQ checks for a new version 5 seconds after it opens and again every 6 hours. You can also check by hand in three places: **⋯ → Check for updates**, the **About** dialog, or the tray menu. When a newer version exists, a message slides down at the top of the window with **Update now**, **What's new** and **Later**.

- **Windows:** **Update now** downloads the installer with a progress bar and checks its SHA-256. It then runs the installer silently, closes SK EQ, and SK EQ reopens on the new version. Settings and presets are kept.
- **macOS:** the `.dmg` is downloaded and opened, and you drag SK EQ into Applications.

Behind the scenes, the app reads a small manifest (`latest.json`):

```json
{
  "version": "1.1.0",
  "notes": "What's new…",
  "notesUrl": "https://github.com/OWNER/REPO/releases/tag/v1.1.0",
  "windows": { "url": "https://…/SK-EQ-Setup-1.1.0.exe", "sha256": "…" },
  "macos":   { "url": "https://…/SK-EQ-1.1.0.dmg",       "sha256": "…" }
}
```

The manifest address is set at build time with `--dart-define=PUREEQ_UPDATE_URL=…`; see `lib/config.dart`. The build scripts pass it on from the `PUREEQ_UPDATE_URL` environment variable. Only HTTPS is accepted, except for `localhost`, which is allowed for testing. A build without an address shows "Updates are not set up for this build yet."

### Releasing an update (GitHub)

1. Bump `version:` in `pubspec.yaml` (for example `1.1.0+2`) and commit.
2. Tag the commit and push the tag. The tag message becomes the release notes:
   ```bash
   git tag -a v1.1.0 -m "Faster spectrum, new presets"
   git push origin v1.1.0
   ```
3. GitHub Actions builds the `.exe` and the `.dmg`, writes `latest.json`, and publishes them as a release. Installed copies then find the update at `https://github.com/OWNER/REPO/releases/latest/download/latest.json`.

## Features

| Area | Details |
|---|---|
| Spectrum | 128 thin glowing bars with peak-hold dots, a dB scale (±12) on the left, and Output / EQ curve toggles. |
| EQ curve | Smooth curve with a control point per band. Drag a point or the line itself, scroll to nudge, double-click to reset a band. It shows what you hear: the bands plus the bass/treble shelves. |
| 10-band EQ | 31 Hz – 16 kHz, ±12 dB in 0.5 dB steps, linked to the curve. Boosts are drawn in bright cyan, cuts in blue. |
| Quick controls | Bass (low shelf, 31–250 Hz) and Treble (high shelf, 4–16 kHz) are layered on top of the bands. |
| A/B Compare | Switches instantly between A (with EQ) and B (bypassed). Shortcut: **B**. |
| Presets | Custom, Flat, Bass Boost, Treble Boost, Vocal, Rock, Pop, Jazz, Classical and Electronic, plus your own (saved with bass/treble). Save Preset lights up when you have unsaved changes. |
| Master volume | Reads and sets the real OS volume and mute, and follows changes made with the media keys. |
| Tray | A tray icon (Windows) or menu bar icon (macOS) with Show, Equalizer on/off and Quit. Closing the window hides SK EQ to the tray, where it keeps running. |
| Window | Frameless window that fits your screen. Windows 11–style caption buttons on Windows; native traffic lights on macOS. |
| Updates | Checks automatically and from **⋯ → Check for updates**. A message at the top offers the new version, and **Update now** installs it and restarts SK EQ. See [Updates](#updates). |
| Shortcuts | **B** = A/B compare, **E** = EQ on/off, **Ctrl/⌘+S** = save preset. |
| Performance | The bars are the only layer redrawn every frame, the curve redraws only while it moves, glows avoid blur filters, and animation pauses while the window is minimized or in the tray. |

## Important: what is real and what is simulated

- **Master volume and mute are real.** They control the system output device.
- **The spectrum is simulated.** Capturing system-wide audio needs a loopback source: WASAPI loopback on Windows, or a virtual device such as BlackHole on macOS. The simulation is shaped by the EQ curve and the volume, so every control changes what you see. To show real audio, feed FFT magnitudes into `SpectrumSimulation.levels`.
- **The EQ does not process system audio yet.** Flutter cannot insert a filter into the OS audio path. `EqState.effectiveGains` holds the final 10 gains in dB, ready to send to a real backend:
  - **Windows:** [Equalizer APO](https://sourceforge.net/projects/equalizerapo/). Write a `GraphicEQ: 31 g1; 63 g2; …` line to its `config.txt`, and it applies the EQ system-wide right away.
  - **macOS:** route audio through a virtual device and apply the EQ with `AVAudioUnitEQ` in a small native plugin. eqMac uses this approach.

`system_tray` was left out because it is optional and needs tray icon assets for each platform. Add it in `main.dart` if you want the app to run from the menu bar or tray.
